The Unity Engine is a ==cross-platform software system used to build 2D and 3D video games, interactive apps, and simulations==. It was created by [Unity Technologies](https://unity.com/) and first released in June 2005.
## Key Features
- **Multi-platform support**: Build and export games for over 20 platforms, including Windows, macOS, iOS, Android, PlayStation, Xbox, and Nintendo Switch.
- **Programming language**: Uses the C# programming language for writing game code and custom logic.
- **Built-in tools**: Includes physics engines, 3D/2D rendering, and lighting systems.
## Main Uses
- **Indie and mobile games**: Very popular for making mobile phone games and independent titles.
- **Other industries**: Used in architecture, automotive, and film to make virtual reality and 3D experiences.
