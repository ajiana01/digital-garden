## 🏗️ About This Repository

This portfolio is built as a Single Page Application (SPA) using **[Quartz 5](https://quartz.jzhao.xyz/)**, a fast, static-site generator optimized for Markdown-based digital gardens.

*   **Content:** Written entirely in Obsidian-flavored Markdown.
*   **Deployment:** Automated via **GitHub Actions** and hosted on GitHub Pages.
*   **Structure:** Designed to showcase both technical snippets (architecture, code logic) and project management case studies (workflow, team coordination).
